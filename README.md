# RAG Intelligence Assistant

An advanced context-aware knowledge retrieval and semantic analysis engine.

## Features
- Upload PDF, Word, Excel, CSV, JSON, HTML, XML, Markdown, plain text, and source code files.
- Document chunking, metadata grounding, and ChromaDB vector persistence.
- High-contrast, glassmorphic visual interface.
- Complete session chat history export.

## Deployment
This repository is configured for deployment to Hugging Face Spaces using the Docker SDK.
