What is AI and Machine Learning?
Artificial Intelligence (AI) refers to the simulation of human intelligence in machines that are programmed to think like humans and mimic their actions. The term may also be applied to any machine that exhibits traits associated with a human mind such as learning and problem-solving. Machine Learning (ML) is a subset of AI that involves the use of data and algorithms to imitate the way that humans learn, gradually improving its accuracy. 

What is Deep Learning?
Deep Learning is a specialized form of Machine Learning that uses artificial neural networks with multiple layers (hence "deep"). These networks are designed to simulate the behavior of the human brain, allowing it to "learn" from large amounts of data. While traditional ML algorithms often require structured data and manual feature extraction, Deep Learning models can automatically extract complex features from raw, unstructured data like images, text, and audio. This capability has driven massive advancements in fields like computer vision and natural language processing.

What is RAG (Retrieval Augmented Generation)?
Retrieval-Augmented Generation (RAG) is a technique that enhances large language models (LLMs) by integrating them with external knowledge sources. Rather than relying solely on the vast but static information an LLM learned during training, RAG allows the system to query a specialized database (like a vector store) in real time. When a user asks a question, the RAG system first retrieves relevant documents or text chunks, and then feeds this context into the LLM along with the original question. This significantly reduces hallucinations, ensures the answers are based on factual, up-to-date information, and allows the model to cite its sources.

How does ChromaDB work?
ChromaDB is a high-performance, open-source vector database specifically designed for AI and Machine Learning applications. It efficiently stores and queries high-dimensional vector embeddings—numerical representations of text, images, or audio generated by embedding models. When new documents are ingested, they are converted into embeddings and indexed by ChromaDB. During a search, the query is also converted into an embedding, and ChromaDB performs a similarity search (using techniques like cosine similarity or Euclidean distance) to quickly find the most relevant document chunks. It is highly favored in RAG applications because it is fast, lightweight, and can be run locally for free.

What is Groq and LLaMA?
Groq is a technology company that developed the Language Processing Unit (LPU), an AI accelerator designed specifically for running LLMs at incredible speeds with low latency. Their platform offers a free tier that developers can use to access cutting-edge open-source models. LLaMA (Large Language Model Meta AI) is a family of state-of-the-art open-source foundational models released by Meta. LLaMA 3.1 represents one of the most capable models available, offering strong reasoning, coding, and general knowledge capabilities. By running LLaMA on Groq's infrastructure, applications can achieve lightning-fast inference times for free.

How does Streamlit work?
Streamlit is an open-source Python library that makes it incredibly easy to create and share beautiful, custom web apps for machine learning and data science. In just a few minutes, developers can build a fully functional user interface without needing to know any front-end languages like HTML, CSS, or JavaScript. Streamlit apps are written entirely in Python, using intuitive commands to add elements like text, buttons, sliders, file uploaders, and chat interfaces. Every time an interaction occurs, Streamlit automatically reruns the Python script from top to bottom, making state management and real-time updates seamless and straightforward.
